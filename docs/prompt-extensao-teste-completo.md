# Teste completo do QuestPlus pela extensão Claude in Chrome

Este arquivo guarda o texto do prompt. **A extensão só aceita criar dados a partir de instruções coladas no chat**, então o texto abaixo deve ser colado na conversa dela (o desenvolvedor recebe a versão pronta para colar na resposta do Claude Code).

O teste cria apenas dados marcados com `[TESTE]` e escreve o relatório em `docs/relatorios/AAAA-MM-DD-teste-completo.md`, na branch `relatorios-extensao`.
